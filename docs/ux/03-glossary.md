# P1 · Glossary (draft for church review)

These definitions power the inline glossary tooltips and the `/glossary` page. Each one is
**supported by the church's own records** (the source is noted) or marked **needs definition**.
Nothing here is guessed. The church confirms or corrects each entry before it is published.
